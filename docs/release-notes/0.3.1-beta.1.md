# Pit Planner 0.3.1-beta.1

A test build. Install it over 0.3.0: do not uninstall first.
How to install or update: [INSTALL.md](https://github.com/MechEng70/pitplanner/blob/main/docs/INSTALL.md).

## What changed

- **No battery limits has more taps now.** Allow used to ask one question. It now opens Pit Planner's App
  info. From there open the app's battery setting and pick no restrictions. On most phones that is App
  battery usage, then the words Allow background usage (not the switch), then Unrestricted. On a OnePlus it
  is Battery usage, then Allow background activity. If you already allowed it in 0.3.0, nothing changes for
  you: it stays on.
- **Full-screen alerts off is not a fault.** When that is the only thing off, Gear's Alerts row reads
  "Ready (full-screen alerts off)". Your alerts still ring.

## Why

Pit Planner is getting ready for Google Play, which does not let an app like this one ask the battery
question directly.
