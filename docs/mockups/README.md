# Pit Planner mockups

PNG exports (390x844 at 2x) of the mockup canvas: https://claude.ai/artifact/HTLvrL9LnmkuoPLip1v9dz

The canvas is the live, editable version. These PNGs are a snapshot for the repo and for Claude Code to look at while building. Re-export after changing the canvas.

`source/` holds the canvas artboard files (.dc.html) and layout (canvas.json) as of this export. They need the canvas runtime to render; open the canvas link to view or edit them.

Numbered in flow order: first launch (01-03), Plan (04-11), Cook (12-15), Gear (16-20).
